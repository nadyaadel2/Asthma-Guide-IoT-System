# Asthma Guide IoT & Mobile System

An IoT-based public health monitoring system engineered to track environmental triggers in real-time and empower chronic illness patients to manage their condition proactively.

## Overview
This capstone project bridges hardware sensors and mobile connectivity to establish an automated public health safety net. By continuously monitoring hazardous environmental factors (such as air quality and humidity), the system protects vulnerable patients through proactive, instantaneous alerts.

## Architecture & Components
- Hardware Unit: Developed using an Arduino Nano integrated with an ESP8266 Wi-Fi module, an MQ135 gas/smoke sensor, a DHT11 temperature/humidity sensor, and an OLED display.
- Mobile Application: Communicates via wireless protocols to let users configure custom environmental safety thresholds and receive instant alerts.
- Testing & Validation: Validated through systematic integration protocols, achieving a rapid 0.5-second system response time for critical triggers.
